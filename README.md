# .github: arquivos padrão da organização GitA8telecom

Repositório especial do GitHub. Os arquivos aqui valem como **padrão para todos os repositórios da organização** que não tiverem uma versão própria.

| Arquivo | Para quê |
|---|---|
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Fluxo de branches (`main`, `qa`, features, hotfix), PRs, commits e regras de segurança |
| [`pull_request_template.md`](pull_request_template.md) | Template padrão de Pull Request |
| `profile/README.md` (opcional) | Página de apresentação da organização |

Regras técnicas que garantem esse fluxo (rulesets, branches `qa`, modos de merge): [`omega-infra/docs/CONFIGURACAO-GITHUB.md`](https://github.com/GitA8telecom/omega-infra/blob/main/docs/CONFIGURACAO-GITHUB.md).
